# Eagle Engineering Ecosystem

A Flutter Android study app with a Go + PostgreSQL backend.

- **EAGLE STUDY** ([apps/eagle-study-android](apps/eagle-study-android)): a stopwatch and countdown timer with session history stored on the device, plus a 12-month learning roadmap and study schedule.
- **API** ([backend/go-services/api](backend/go-services/api)): Go + PostgreSQL for study sessions, preferences and stats. Sign-in uses Neon Auth.

Alarms, Study Mode controls, the 3D eagle and phone-to-API sync aren't built yet. [IMPLEMENTATION_CHECKLIST.md](IMPLEMENTATION_CHECKLIST.md) tracks what is done, and [ARCHITECTURE.md](documentation/architecture/ARCHITECTURE.md) explains the design.
